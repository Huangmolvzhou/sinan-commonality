What it is

司南
能帮你做什么

它做的事只有一件：看到一批不良，告诉你这批板有没有共同点、共同点在哪、下一步该去查谁。 你只要选「项目 / 时间 / 工站 / 点位 / 不良现象」，它自己进 MES 把机台、吸嘴、飞达、载具、钢网、 材料批次、SPI 与 AOI 的测量值全拉出来，和同批正常板一条条对照，最后给你几个带倍数的结论。

以前要人工干的事

导 AOI 明细、导贴装记录、查载具、查材料批次、一张张对，一个案子半天到三天。数对了还不一定看出共性。

现在它替你做的

同一个案子十几秒。每条结论都带「不良率 / 全场不良率 / 倍数 / 校正后 p 值」，能直接贴进报告和检讨会。

它不做什么

不给「一定就是这个原因」的假结论。样本不够、检验没通过、可能是被动共现，它会直接写明，不会替你盖章。

它对数据库做了什么

只读，物理只读副本。代码层还有一道只读熔断，任何写操作在发出去之前就被拦掉。不会改 MES 任何一个字。

「分散」也是结论 —— 而且是很有用的那种。
以前查完没找到共性，只能写「未发现明显共性」。现在工具会说：这是分散，当前样本里没集中在某一台机 / 某一把吸嘴，不等于已经排除，下一步该往哪看。

Use it like this

我可以用它做什么

按你手上的活来挑，一条一条对。

Post AOI 不良定位最常用
手上有一批不良（比如 Clip 偏移、缺件、立碑），想知道是不是某台贴片机 / 某把吸嘴 / 某个穴位做的。 选好工站、点位、现象，点「开始分析」。工具会给风险比：这个穴位的不良率是基准的几倍、 校正后还显不显著。倍数高且检验通过，才值得去查。
怀疑载具 / 钢网载具 · 跨工单
怀疑某个载具或钢网伤了板子？工具会把这个载具在别的工单里的表现一起拉出来。 只在你这单坏、别的单没事 → 大概率是这批材料或这次手法；到处都坏 → 载具本身该换了。
怀疑同一把吸嘴跨机台
吸嘴是会换机台用的。工具会把同一把吸嘴 / 同一个飞达在多台机上的表现并排放， 用两比例检验告诉你：是机台的问题，还是这把吸嘴自己的问题。
怀疑材料批次材料三兄弟
料号 / 厂商 / 批次三个维度分开算，钢网也单独占一维。某个批次明显偏高，还能顺着板号反查到具体是哪一盘料。
测量值到底偏没偏SPI / AOI
不是看「这条不良长什么样」，是看数值有没有分开：NG 板的 OffsetX / Rotation / Height 分布 和正常板比，落在规格外的比例差多少，五张小图一次画全（含上下规格线）。
是不是这次才变差慢性 / 突发
跟你前 7 天（可改 3/14 天）的同点位比。最近这波是慢性一直在出，还是突然新增？ 还会画出按天与按小时的分布，单天的孤立尖峰单独标出来，不会被说成「整体在恶化」。
一堆维度都集中被动共现
载具 90 号穴位有异物，会连带让材料批次、贴那个穴位的吸嘴和轨道都显得集中—— 但它们本身没问题。工具会把每个显著项剔掉别的项重算一遍：掉下去的判「被动共现」并点名是谁拖的， 没掉的判「它自己也有问题」。这一层直接决定你该改哪一台。
后段测试判 NG前后段联动 · SN 追溯
手上有后段（VSWR / AVI / ICT…）的 NG 板？输入 SN，工具反查它在 SMT 是哪台机、哪把吸嘴、 哪个载具做的，并判首因还是传导：这批板 99% 是在本工序第一次被判 NG，还是前站就已经坏过、 这里只是照出来。
要给主管一份结论一键导出
「导出结论报告」直接出一份 HTML：结论、显著信号、被动共现、时间分布、排查动作清单（查什么 / 怎么查 / 判据）、明细。 不用再手拼 PPT，也不用担心数字抄错。要原始数据就导 CSV。

一句话记住口径：倍数高只是「看起来可疑」，还要过统计检验（跨维度校正后 p < 0.05）才算信号。 工具会对一次分析里所有维度一起做多重比较校正，避免「看得多就总有假信号」。达不到就明说分散，不硬凑。

STEP 01
双击启动
解压后双击「启动工具」（Mac .command / Win .bat），浏览器自己会开。不用装任何东西。
STEP 02
选四样东西
项目、时间、工站、不良点位或现象。选完上一层，下一层会自动收敛，不会让你在几千个选项里找。
STEP 03
点「开始分析」
十几秒出结果。想留证据就点「导出结论报告」，一份 HTML 直接发给主管。
告诉我这些，我能改得更快
  • 你当时选了什么：项目 / 时间 / 工站 / 点位 / 现象。工具里有个「意见反馈」，能一键复制当前筛选条件。
  • 你觉得哪里不对：是数字不对（该高的没高、该低的没低），还是话不对（结论读不懂、说错了方向）。
  • 你实际是怎么查的：你手工查了哪些表、最后查出什么。这条最值钱——工具就是照你的查法长出来的。
  • 你想要什么新东西：新的维度、新的图、新的判定。说得越具体越好，比如「我想看这个穴位在别的项目里有没有同样的集中」。

现在的版本跑在你自己电脑上，双击就能开，不装任何东西，也不用连服务器。 遇到「连不上数据库」先看一眼 VPN；其它报错直接发我截图。
