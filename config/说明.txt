这个 config 文件夹里放的是数据库连接信息。

【为什么要放这里】
打包发给同事后，同事双击「启动工具」就能直接用，不用每个人再填一遍账号密码。

【里面两个文件】
mes.local.json  → 前段 SMT 库（<MES_HOST>）
be.local.json   → 后段 BE 库（<BE_HOST>）
两个都是只读账号，工具代码层也做了 SELECT 白名单，改不了任何数据。

【想换成自己的账号怎么办】
不用改这里。在你自己的电脑上新建这两个文件即可，优先级更高、会盖掉这里的：
  Mac/Linux： ~/.config/sinan/mes.local.json  和  ~/.config/sinan/be.local.json
  Windows  ： C:\Users\你的用户名\.config\sinan\mes.local.json（同理 be.local.json）
内容格式和这里的完全一样，把 user / password 换成你自己的就行。

【注意】
这个文件夹只在本公司内网/VPN 下有用。离开内网，工具照常能开，但查数据时会提示「连不上 MES 数据库」。

【另外两个可选文件】
ch.local.json      → ClickHouse 地址（指标区分度、AOI/SPI 测量值对照用）
contact.local.json → 作者邮箱/电话（右上角「意见反馈」按钮用）
两个都可以不填：不填时「指标区分度」和「测量值对照」标成不可用，
「意见反馈」显示「这一份没有预置维护者联系方式」，其余功能完全正常。
格式见同目录的 ch.example.json / contact.example.json。

【这个目录在开源仓库里是什么状态】
仓库里只有 *.example.json（示例）。真实配置一律是 *.local.json，
已经被 .gitignore 挡在仓库外，不会被推上去。
